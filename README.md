# 贴吧新帖推送

定期检查一个可配置的贴吧，将新发布的主题帖标题、发帖人、内容预览和链接发送到指定 QQ 群。
支持 AstrBot 的 OneBot v11（aiocqhttp）适配器，复用 AstrBot 已有的 aiohttp 依赖，无需额外安装依赖。

## 安装

在 AstrBot 插件管理中通过仓库链接安装：

```text
https://github.com/Pleasure199/astrbot_plugin_tieba
```

也可以在 AstrBot 根目录执行：

```bash
git clone https://github.com/Pleasure199/astrbot_plugin_tieba.git data/plugins/astrbot_plugin_tieba
```

加载插件后，按照下方说明配置贴吧和接收群。

## 配置

在 AstrBot 插件管理中加载 `astrbot_plugin_tieba`，打开插件配置：

| 配置项 | 说明 |
| --- | --- |
| 启用贴吧新帖推送 | 总开关，默认开启 |
| 监听的贴吧名称 | 贴吧的实际名称，例如 `python`，不要填网址或额外追加“吧” |
| 接收新帖的 QQ 群号 | 群号列表，例如 `["123456789", "987654321"]`，机器人需要已入群 |
| OneBot v11 平台实例 ID | 消息平台配置中的 ID；只有一个 aiocqhttp 实例时可留空 |
| 新帖检查间隔 | 默认 60 秒，最少 10 秒 |

保存配置后重载插件。未填写贴吧名称或群号时不会发起请求。无需在群内执行订阅命令。

## 推送规则

- 第一次成功检查只建立基线，不发送历史帖子。修改贴吧名称后也会重新建立基线。
- 后续按发帖时间检查新主题帖，按时间从旧到新推送；旧帖收到新回复不会触发推送。
- 发帖人优先显示当前昵称，昵称不可用时回退到用户名；使用较新客户端版本请求，避免旧接口返回“贴吧用户_…”形式的默认显示名。
- 内容预览使用帖子摘要中的文字：不足 10 个字时完整显示；达到 10 个字时显示前 10 个字并追加“······”。无文字的帖子显示“（无文字内容）”。
- 置顶帖不会使分页提前结束。接口发现较多新帖时会继续翻页到上次进度。
- 新帖和各群的待发送记录先保存到 AstrBot 插件 KV 存储，再发送消息；重载或重启后继续处理。
- 一个群发送失败不影响其他群；该群下一轮从失败的帖子继续重试，成功的群不会重复发送。
- 移除的群不再重试待发送消息；新增的群接收之后发现的新帖，不补发已经发现的帖子。
- 关闭总开关期间保留进度，重新启用后补发接口仍能查询到的新帖。

示例消息：

```text
【python吧 · 新帖】
帖子标题
发帖人：贴吧用户
内容：这是一段用于演示的贴······
https://tieba.baidu.com/p/123456789
```

此插件通过轮询提供近实时通知，延迟通常为一次检查间隔加上请求和发送耗时。
贴吧接口可能受到风控、内容审核、删除或分页可见范围限制；检查失败会写入插件日志并于下轮重试，无法保证接口未返回帖子的完整性。
如果进程恰好在消息发送成功后、发送记录保存前退出，重启后这条消息可能重复发送。
